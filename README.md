# smart-clipping

Універсальний skill для Claude Code: нарізає довге відео (інтерв'ю, подкаст,
talking head) на короткі кліпи **по межах слів**, а не по таймкодах.

- **Фаза 1** — відбір кліпів з транскрипту (qa / framework / story) → план на узгодження.
- **Фаза 2** — після «ріж»: пословний whisper → різ рівно на початок першого й кінець останнього слова → перевірка готових файлів перетранскрибуванням.

Таймкоди з транскрипту тільки задають вікно пошуку, тому зсув ±10-45 с не ламає різ.

## Встановлення

```bash
mkdir -p ~/.claude/skills && cd ~/.claude/skills
git clone https://github.com/dpechenchis-design/smart-clipping.git
brew install ffmpeg
pip3 install faster-whisper
```

Відео віддається сирим: без заголовків, субтитрів і чорних полів — це наступний етап монтажу.
